# Package 03: Business Domain Specification (`/docs/packages/03_BUSINESS_DOMAIN.md`)

## 1. Overview
The **Business Domain** specification defines the core procurement, plant IoT telemetry, and compliance contexts driving the InduCore platform.

## 2. Bounded Contexts
1. **Procurement Bounded Context**: Core domain managing RFQ issuance, line item requirements, vendor bid collection, and automated Gemini AI evaluation.
2. **Plant IoT Telemetry Context**: Supporting domain monitoring plant equipment sensors (vibration, temperature, pressure) and detecting operational drift.
3. **ISO Compliance & Audit Context**: Generic domain maintaining an immutable transaction log of all aggregate state transitions for ISO/IEC 27001 auditability.

## 3. Ubiquitous Language Glossary
- **Tenant**: Isolated corporate enterprise (`TenantId`).
- **RFQ**: Request For Quotation specifying requested material line items (`RFQAggregate`).
- **RFQ Line Item**: SKU, description, quantity, and target price (`RFQLineItem`).
- **Supplier Bid**: Vendor proposal detailing bid amount, currency, and lead time (`SupplierBid`).
- **AI Score**: Composite rating (0–100) generated by `GeminiAIService` evaluating bid competitiveness.

## 4. Domain Invariants
- An RFQ cannot be evaluated by AI if zero bids have been submitted.
- Bids cannot be submitted against closed or archived RFQs.
- All monetary quantities must specify currency codes (`Money` VO).
