# Package 10: AI Specification (`/docs/packages/10_AI.md`)

## 1. Overview
Defines server-side Google Gemini API integration standards using `@google/genai` TypeScript SDK.

## 2. Gemini Integration Standards
- **Model**: Recommended default model `gemini-2.5-flash` for high-throughput multimodal evaluation and structured output extraction.
- **SDK**: Strictly `@google/genai` (`GoogleGenAI` initialization pattern).
- **Execution**: Server-side only inside `GeminiAIService` (`packages/infrastructure/src/ai/GeminiAIService.ts`).
- **Structured Output**: Temperature `0.1` for deterministic bid matrix score evaluation.

## 3. Gemini Service Interface
```typescript
export interface IGeminiAIService {
  evaluateBids(rfq: RFQDTO, bids: BidDTO[]): Promise<AIEvaluationResult[]>;
}
```
