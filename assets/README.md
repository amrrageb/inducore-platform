# InduCore Media & Architecture Assets (`/assets`)

This directory contains visual design assets, brand identity guidelines, UI mockups, and architectural system diagrams for the **InduCore** platform.

---

## 🎨 Asset Categories

| Subfolder | Description |
| :--- | :--- |
| `diagrams/` | High-resolution Clean Architecture layer diagrams, sequence charts, and DDD context maps. |
| `branding/` | Logotypes, monochrome badges, and color system specifications. |
| `ui-mockups/` | High-fidelity Figma exports and responsive web dashboard layouts. |

---

## 📐 Guidelines
1. Vector formats (`SVG`) are preferred for diagrams and icons.
2. Raster images (`PNG`, `JPG`) must be compressed and formatted at 2x resolution for retina displays.
